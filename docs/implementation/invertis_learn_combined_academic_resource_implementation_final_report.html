4. Curator Dashboard Extension & Scheduled Monitoring

A dedicated Academic Resource Manager has been added to /admin to give curators complete operational control over all 79 tracked resources.

  • Filter & Audit: Real-time filtering by programme, format, verification status, and search query.
  • Live Outbound Probing: Curators can trigger an immediate SSRF-guarded HEAD check on any resource.
  • URL Replacement: Broken or dead video/playlist links can be updated directly from the modal interface.
  • Automated Scheduled Monitoring: scripts/monitor-resource-health.js runs weekly via GitHub Action .github/workflows/academic-resource-health.yml.
  • Student Broken Link Reporting: Student submissions from the subject page flag dead links for instant curator review.
